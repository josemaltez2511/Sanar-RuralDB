# Sanar-RuralDB

Base de datos del proyecto Sanar Rural.

## Tecnologías

- SQL Server 2022
- SQL Server Management Studio

## Estructura

La base de datos contiene la estructura para gestionar:

- Pacientes
- Contactos de emergencia
- Doctores
- Especialidades
- Hospitales
- Citas
- Consultas médicas
- Signos vitales
- Diagnósticos
- Medicamentos y prescripciones
- Enfermedades y síntomas
- Usuarios y roles

## Database

El script database/01_Schema.sql crea la estructura de la base de datos SanarRuralDB.

## Contexto

Proyecto académico de desarrollo de un sistema para la gestión de pacientes y atención médica.
